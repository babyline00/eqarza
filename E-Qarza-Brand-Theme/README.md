# E-Qarza Brand Theme

This package contains a complete starter design system based on the supplied E-Qarza logo.

## Main brand colors

- Primary Orange: `#FE6601`
- Orange Hover: `#E95700`
- Orange Dark: `#CC4900`
- Orange Soft: `#FFF0E5`
- Brand Navy: `#1F2D38`
- Navy Secondary: `#344955`
- White: `#FFFFFF`
- Background: `#F7F9FA`

## Recommended usage

### Orange
Use for:
- Primary CTA buttons
- Active navigation
- Important links
- Financial highlights
- Icons
- Progress indicators
- Brand accents

### Navy
Use for:
- Main headings
- Body text
- Sidebar/dashboard
- Footer
- Trust/security sections

### Light Orange
Use for:
- CTA hover backgrounds
- Selected cards
- Notification backgrounds
- Feature icon backgrounds
- Badges

### White / Light Gray
Use for:
- Main surfaces
- Forms
- Cards
- Tables
- Dashboard backgrounds

## Files

- `theme.css` — complete reusable CSS design system
- `index.html` — working responsive design demo
- `logo.jpeg` — supplied E-Qarza logo
